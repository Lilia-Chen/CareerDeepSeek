# Browser-use Policy

DeepJobSeek is not a crawler.

## Allowed

- Visible browser or computer-use under user supervision.
- User-approved pages only.
- Low-frequency page opening.
- Reading visible current-page text.
- Screenshot-assisted understanding.
- Drafting summaries and messages for user approval.
- Writing local private CRM records to `DEEPJOBSEEK_DATA_DIR`.

## Forbidden

- Raw HTTP scraping.
- Hidden API reverse engineering.
- sitemap crawling.
- CAPTCHA bypass.
- Proxy rotation.
- Headless bulk collection.
- Background unattended scraping.
- Bulk extraction from job boards, social networks, review sites, or salary sites.
- Auto-apply.
- Auto-send messages.
- Auto-add connections.
- Auto-like, comment, or follow.

## Approval gates

Ask before:

- Opening more than a few pages from a platform site.
- Logging in.
- Handling account or security prompts.
- Saving contact data.
- Generating a real outreach draft.
- Writing private CRM records.
- Changing platform-specific behavior.
